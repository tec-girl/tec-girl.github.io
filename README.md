# Tec Girl — Hacker Web Designer

Sitio personal de **Tec Girl**, diseñadora web con estética cyberpunk: neón turquesa, rosa y morado sobre negro, con terminal interactiva y diseño editorial.

## Secciones

- **Bio** — quién es Tec Girl.
- **Servicios** — diseño web y experiencias digitales.
- **Páginas** — la red de sitios que ha construido (Keysi Kunz, Ximena Grace, Jaqui Salinas, SmartTwin, insta-followers y más).
- **Personal** — su página personal (`personal.html`).
- **Amigas, Juego y Foro** — espacios de comunidad.

## El sitio

- Estático, en HTML, CSS y JavaScript puro, sin compilación.
- Disponible en **seis idiomas**: español, English, français, Deutsch, 中文 y português.
- Base: Puebla, México, para el mundo.

| Archivo | Función |
| --- | --- |
| `index.html` | Página principal |
| `personal.html` | Página personal |
| `script.js` | Lógica principal e interactividad |
| `personal.js` | Lógica de la página personal |
| `style.css` | Estilos principales |
| `personal.css` | Estilos de la página personal |
| `assets/` | Imágenes y recursos |

## Cómo ejecutarlo

Abrir `index.html` en un navegador moderno, o servir la carpeta:

```bash
python3 -m http.server 8000
```
